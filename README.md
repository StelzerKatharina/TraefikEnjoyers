# TraefikEnjoyers

Simple web app for Subtask 1.1 (wild cam observation logging).

## Run

Open `/home/runner/work/TraefikEnjoyers/TraefikEnjoyers/index.html` in a browser.

## Usage

Enter:
- animal name
- stream name
- date/time when it was visible

Click **Add observation** to append the entry to the on-screen log.
